# 基于 IP 地址过滤，已无法有效识别 DNS 污染

DNS 污染返回的 IP 地址已经不再具有明显的地域特征，基于 IP 地址归属地的过滤方式因此失去了判断依据。

过去，DNS 污染返回的错误 IP 往往集中在某些特定的 IP 地址段，或者表现出明显的地域特征。

例如，在境内网络环境下查询境外域名，污染结果可能返回一个归属于中国大陆的 IP。

因此，可以通过 GeoIP 等数据库，过滤掉属于中国大陆的 IP 地址，间接识别和排除一部分污染结果。

但情况早已发生了变化。

污染结果可能来自世界各地，包括美国、日本、韩国等不同国家和地区。它们在地域分布上不再具有明显规律，甚至可能与目标服务器所在的地区一致。

这意味着，基于 IP 地理位置的过滤开始面临两个问题：

1. 无法有效识别污染结果。 污染 IP 可能来自任意地区，仅凭地理位置已经无法判断其真实性。
2. 容易误过滤正常结果。 目标服务器本身也可能位于这些地区，过滤 IP 地址段可能同时排除正确的解析结果。

想要获得可信的解析结果，应当从可信的 DNS 服务器和可验证的查询通道入手，而不是试图从一个未经验证的 IP 地址中判断它是否正确。
